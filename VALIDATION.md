The real-CDN Chromium integration also passed with all 12 integrity-checked dictionaries and no browser errors.

The browser harness simulates the documented Spicetify APIs and supported Spotify DOM layouts. Live UI checks used the user's running Spotify Desktop on a two-display Windows system, with window-specific targeting. A real startup exception in the profile-menu constructor was identified and fixed by waiting for the ReactJSX runtime. No account information, tokens or live song lyric screenshots are included in this repository. No claim of universal Spotify-version or third-party lyrics-extension compatibility is made.

The repository's CI repeats the offline regression suite, manifest validation, dependency audit and clean-build comparison on Linux with Node.js 22. CDN browser testing is a separate developer command because it depends on network availability.
